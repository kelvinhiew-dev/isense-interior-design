# iSense Interior Design

Landing page for iSense Interior Design: interior design and custom carpentry.
English / 中文, with WhatsApp contact (012-3299880).

## Files

- `index.html`: the whole page (styles and scripts are inside)
- `isense-logo.png`: company logo

## Change the WhatsApp number

Open `index.html`, find these two lines near the bottom and edit them:

```js
const WA_NUMBER = "60123299880";   // country code + number, digits only
const WA_DISPLAY = "012-3299880";  // how the number is shown on the page
```

## View it

Open `index.html` in any browser.
